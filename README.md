🌟 Bin — A Simple Programming Language 🚀

Bin is a lightweight, beginner-friendly programming language created for learning and experimentation.
It focuses on clarity, simplicity, and ease of understanding, making it perfect for students, hobbyists, or anyone curious about how programming languages work.

🔥 Why Bin?

✨ Simple Syntax – Write clean, readable code without unnecessary complexity.
⚡ Quick to Try – Designed for demonstrations and learning.
💡 Beginner-Friendly – Great for newcomers to programming.
🌐 Expandable – The structure allows easy experimentation with new features.

✨ Core Concepts Demonstrated
✅ Variables (VAR)
✅ Basic Arithmetic & Expressions (+, -, *, /)
✅ Conditionals (IF, ELSE, ELIF)
✅ Loops (FOR, WHILE)
✅ Functions (FUN)
✅ Lists and Simple Data Structures
