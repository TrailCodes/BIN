🌟 FLUX — A Simple Programming Language 🚀

Welcome to FLUX, a lightweight programming language created for learning and experimentation.
FLUX focuses on clarity and simplicity, making it easy to understand how programming languages work under the hood.

🔥 Why FLUX?

✨ Simple Syntax – Write code that’s easy to read and understand.
⚡ Quick to Try – Designed for demonstrations and learning purposes.
💡 Beginner-Friendly – Perfect for students and newcomers to programming.
🌐 Expandable – The language structure allows you to add new features for practice.

✨ Core Concepts Demonstrated
✅ Variable Declaration & Assignment (VAR)
✅ Basic Arithmetic & Expressions
✅ Conditional Statements (IF, ELSE)
✅ Loops (FOR, WHILE)
✅ Functions (FUN)
✅ Lists and Simple Data Structures

⚙️ Getting Started
Download FLUX source code.
Open the interpreter or run the Python script implementing FLUX.
Try writing simple programs like printing text, using loops, or defining functions.
